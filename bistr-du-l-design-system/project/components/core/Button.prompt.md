One-sentence: the brand's button; `cta` (terracota) is reserved for "Reservar uma mesa" and hover accents, `outline` for secondary actions, `quiet` for inline text actions.

```jsx
<Button variant="cta">Reservar uma mesa</Button>
<Button variant="outline" href="#menu">Ver o menu</Button>
<Button variant="quiet" size="sm">Falar no WhatsApp</Button>
```

Radius is 4px by default. `pill` exists but must not appear more than twice on a screen.
