One-sentence: renders an official Bistrô du Lú lockup at a given height; use `monogram` in headers, `vertical` for hero/footer, `horizontal` only on light (areia) backgrounds.

```jsx
<Logo variant="monogram" height={40} />
<Logo variant="vertical" height={120} />
```

The clara (sand/rose) lockups are for dark vinho/carvão surfaces; the escura (wine) lockup is for areia surfaces. Minimum monogram height 28px. Never place the mark on a photo without a protection gradient.
